弧光工艺台 V1.5 - 工装电梯长度反算版

本版新增：
1. 焊道长度来源可选“工装电梯起止设定值”或“手动填写”。
2. 输入起点、终点，按绝对差值计算行程。
3. 支持mm、cm和设备刻度/脉冲。设备刻度必须填写经过现场标定的“每单位对应毫米”。
4. 可扣除起点和终点非焊接余量，得到有效焊接长度。
5. 有效长度自动进入焊道面积反算：当天面积=当天道数×有效长度(m)×有效计价宽度(mm)/1000。

重要：电梯行程不必然等于实际焊接长度。请确认设定值与实际位移的比例，并根据引弧/收弧、夹具边界和工件有效覆盖范围设置余量。先用已知尺寸工件校准，不要将未经验证的数值直接用于工资争议或工艺放行。

使用：解压后通过浏览器打开index.html。数据保存在当前浏览器本地，定期使用程序内“备份”导出JSON。PWA主屏幕安装需要HTTPS静态站点。
