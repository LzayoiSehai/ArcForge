⚙️ ArcForge · 弧光工艺台

«离线焊接生产记录、工艺辅助与通用核算工具»

ArcForge 是一个面向焊接从业者的轻量级本地工具，提供生产记录、焊道面积核算、工艺参数整理及个人数据管理功能。

数据默认保存在当前浏览器本地，不会自动上传到云端。

✨ 核心功能

- 生产记录：录入工件、工艺类型、面积、数量及自定义核算参数。
- 焊道核算：支持按工件卡面积分摊或按焊道长度、有效宽度进行几何反算。
- 出勤记录：区分实际作业、等待/待工与调休。
- 通用金额核算：允许使用者自行设置核算参数，计算结果仅供个人记录与估算。
- 储蓄规划：记录目标、支出和预计结余。
- 工艺助手：支持母材、焊材、保护气体、设备及 WPS 参数记录，并提供电弧能量计算。
- 离线使用：支持 PWA，可添加到手机桌面，在支持的浏览器中离线访问。

🛠️ 技术栈

- HTML5 / CSS3 / Vanilla JavaScript
- 使用浏览器 "localStorage" 进行本地数据持久化
- PWA（Progressive Web App）离线缓存
- 无需后端服务器及数据库即可运行

📦 本地运行与数据备份

克隆仓库：

git clone https://github.com/LzayoiSeHai/ArcForge.git
cd ArcForge

使用浏览器打开项目入口文件即可运行。

若通过 GitHub Pages 或其他静态托管服务部署，请确保入口文件名与 Pages 发布目录配置一致。

数据提醒：

记录保存在当前浏览器本地。更换设备、清理浏览器数据或卸载应用前，请使用程序内的「备份」功能导出 JSON 文件，并在新设备上通过「恢复」导入。

⚠️ 使用边界

- 本项目用于个人记录、通用核算和工艺资料整理，不替代企业正式计价制度、质量检验报告或工艺文件。
- 工艺参数必须以适用的材料证明、批准的 WPS/PQR、设备说明及现场验证为准。
- 计算结果不构成焊接工艺评定、质量放行或安全操作许可。
- 请勿将企业内部文件、未公开工艺参数或个人敏感信息提交到公开仓库。
