# ⚙️ ArcForge · 弧光工艺台

> 离线焊接计件工资、出勤、工资反推与储蓄目标工具

这是一个专为焊接工人设计的个人核算与现金流管理工具。所有数据默认保存在浏览器本地，**不上传云端，保护个人隐私**。

## ✨ 核心功能

- **计件录入**：支持底层、面层、单层堆焊核算，结合厚度、道数、耗丝阈值自动计算工资金额。
- **焊道核算**：支持“工装电梯行程反算”，通过起止设定值自动计算有效焊接长度和面积。
- **出勤记录**：区分实际作业、到厂待工与调休。
- **工资核算/反推**：自动扣除五险一金及个税，并支持根据目标实发工资反推所需计件额。
- **储蓄目标**：规划考证支出与转职储备，计算每月所需结余。
- **工艺助手**：WPS参数记录与热输入计算器。
- **离线可用**：支持 PWA 技术，可添加到手机桌面，无网络也能使用。

## 🛠️ 技术栈

- 纯 HTML5 / CSS3 / Vanilla JavaScript（无框架依赖，极速加载）
- 基于 `localStorage` 的本地数据持久化
- PWA (Progressive Web App) 支持离线访问

## 📦 本地运行与数据备份

1. 克隆仓库或直接下载 `index.html`。
2. 用浏览器打开 `index.html` 即可运行。
3. **⚠️ 数据提醒**：数据存储在浏览器 LocalStorage 中。换设备或清理浏览器缓存前，请务必使用顶部“备份”功能导出 JSON 文件，新设备使用“恢复”导入。
